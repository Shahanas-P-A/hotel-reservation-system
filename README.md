# 🏨 LuxeStay MS - Hotel Reservation System

A Hotel Reservation System developed using PHP and MySQL for managing customers, rooms, and reservations through an admin dashboard.

## ✨ Features

- 🔐 Admin Login Authentication
- 👥 Customer Management
- 🛏️ Room Management
- 📅 Hotel Room Booking
- 📊 Dashboard Statistics
- 📜 Reservation History
- 💰 Revenue Calculation
- 🔍 Customer Search
- 📱 Responsive Design

## 🛠️ Tech Stack

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP
